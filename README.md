# 구매 분석 대시보드 — 톤급·모델별 협력업체 비중 분석

> 🌐 **배포 페이지: [https://aebonlee.github.io/hd-project01/](https://aebonlee.github.io/hd-project01/)** · 저장소: https://github.com/aebonlee/hd-project01

빅데이터 기반 **장비 모델별 구매 품목 및 협력업체 분석 대시보드** (기획: 정하진 · 생성형 AI 업무자동화 전문가과정 1차수)

구매 데이터와 장비 모델 데이터를 **품번(Part Number) 기준으로 조인**하여,
**톤급 → 장비 모델 → 품번 → 협력업체** 계층으로 드릴다운하면서 구매 물량·금액과
업체별 비중(%)·집중도를 한눈에 확인할 수 있는 웹 대시보드입니다.

## 실행 방법

빌드·설치가 필요 없습니다. 라이브러리(SheetJS, Chart.js)가 저장소에 포함되어 있어 오프라인에서도 동작합니다.

1. 저장소를 내려받고 `index.html`을 브라우저(크롬 권장)로 엽니다.
   - 또는 GitHub Pages로 배포하면 링크만으로 사용 가능합니다. (Settings → Pages → 브랜치 선택)
2. **[샘플 데이터 불러오기]** 버튼으로 즉시 데모를 확인하거나,
3. 실제 엑셀 2개를 업로드합니다.
   - ① 구매 데이터: `품번`, `업체명`, `연간 구매 물량`, `연간 구매 금액`
   - ② 장비 모델 데이터: `품번`, `장비 모델명`, `톤급 코드`
   - 첫 번째 시트의 1행을 헤더로 인식하며, 컬럼명은 유사 명칭(예: 업체/협력업체/vendor, 모델명/model)도 자동 매핑됩니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 품번 기준 조인 | 구매×모델 데이터 조인. 1:N 품번(여러 모델 적용)은 기획서 기준대로 **모든 모델에 연계** |
| 톤급 변환 | `2X→2톤급 … 8X→8톤급`, `100→10톤급 … 180→18톤급` (3자리 수는 ÷10). 정렬은 숫자 순 |
| KPI | 연간 구매 금액/물량, 품번 수, 업체 수, 집중도 경고 건수 (구매 원본 기준 — 1:N 중복 없음) |
| 드릴다운 | 톤급 → 모델 → 품번 → 업체 아코디언. 각 레벨에 물량·금액·업체 점유 막대 |
| 차트 | 톤급별 구매 규모(막대, 클릭 시 필터), 업체별 비중 도넛(상위 8개사 + 기타) |
| 필터 | 톤급 / 모델 / 업체 / 집계 기준(금액·물량) / 집중도 경고 기준(%) |
| 업체 집중도 | 1위 업체 비중이 기준(기본 50%) 이상인 모델·품번 하이라이트 및 목록 |
| 보고서 | 요약 보고서 인쇄(브라우저에서 **PDF로 저장**) — 톤급별 규모, 모델별 업체 비중, 집중도 상위 |
| 엑셀 내보내기 | 톤급별 / 모델×업체 / 집중도 시트로 구성된 결과 엑셀 다운로드 |

## 집계 기준 주의사항

- 하나의 품번이 여러 모델에 적용되면(1:N) 드릴다운 트리에서는 해당 품번의 물량·금액이 **모델마다 중복 집계**됩니다(기획서 요구사항).
- 상단 KPI와 업체별 비중 도넛은 **구매 데이터 원본 기준**(품번×업체 유일)으로 계산하여 중복을 제거합니다.
- 모델 데이터에 없는 품번은 **미분류**로 표시됩니다.

## 폴더 구조

```
index.html          대시보드 (단일 페이지)
css/style.css       스타일
js/analysis.js      핵심 분석 로직 (조인·톤급 변환·집계·집중도) — UI 독립, Node에서도 동작
js/app.js           UI·차트·내보내기
js/sample-data.js   임베디드 샘플 데이터 (자동 생성)
lib/                SheetJS, Chart.js (로컬 번들)
data/               샘플 엑셀 2종 (purchase.xlsx, model.xlsx)
make_samples.py     샘플 데이터 생성 스크립트 (python3, openpyxl)
test/               로직 단위 테스트 (node test/analysis.test.js)
```

## 테스트

```bash
node test/analysis.test.js   # 톤급 변환·조인·집계·집중도·KPI 검증
python3 make_samples.py      # 샘플 데이터 재생성 (data/*.xlsx, js/sample-data.js)
```

## 실제 데이터 적용 팁

- 헤더 행이 1행이 아닌 경우: 엑셀에서 헤더 위 행을 삭제한 뒤 업로드하세요.
- 톤급 코드가 `2X~9X`, `100~999` 외 형식이면 `js/analysis.js`의 `parseTonCode`에 규칙을 추가하면 됩니다.
- 컬럼명이 자동 인식되지 않으면 `js/analysis.js`의 `COLUMN_ALIASES`에 실제 컬럼명을 추가하세요.
